# Ethics

Dark patterns this skill refuses, the guardrails that replace them, and the check applied to every mechanic before it can ship.

## Dark patterns

| Dark pattern | Looks like | Check passes when |
| --- | --- | --- |
| Loss-aversion abuse | status or streak framed as about to be lost, to force a return | no mechanic threatens loss of status to force a return |
| Fake urgency | an artificial countdown or scarcity with no real deadline | every deadline shown is real |
| Shame or guilt messaging | "you're letting your team down", broken-streak shaming | copy on a missed day or lapse is neutral, never shaming |
| Infinite loops | rewards with no end state, engagement pursued for its own sake | the mechanic connects to a real, finite outcome or habit, not engagement alone |
| Pay-to-recover | charging money to restore a lost streak or status | recovering a lost streak or status costs no money |
| Hidden opt-out | notifications or mechanics with no visible way to turn off | the mechanic can be turned off in one visible step |
| Manipulation of vulnerable users | exploiting anxiety, loneliness, or compulsive tendencies for engagement | the mechanic was not designed around anxiety, loneliness, or compulsion |

## Guardrails

| Guardrail | Rule |
| --- | --- |
| Rest days | the loop tolerates a planned or unplanned pause with no penalty beyond a soft reset |
| Opt-out | every mechanic can be turned off without losing access to the core product |
| Transparency | the rule behind every mechanic (how it is earned, how it decays) is visible to the user |
| Caps | notifications and prompts carry a daily or weekly ceiling |
| Proportionality | celebration intensity matches frequency and consequence, per `celebrations` |
| Calm by default | the resting state of the product is calm; engagement mechanics are additive, never the baseline |
