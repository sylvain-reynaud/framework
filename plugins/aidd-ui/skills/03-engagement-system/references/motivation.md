# Motivation

Self-Determination Theory needs, intrinsic versus extrinsic drive, and the Hexad player types. One row per need or type: the mechanic that serves it, and the one that backfires.

| Need or type | What it wants | Mechanic that serves it | Mechanic that backfires |
| --- | --- | --- | --- |
| Autonomy (SDT) | choice and control over the path taken | personalization, optional challenges | a forced daily goal with no opt-out |
| Competence (SDT) | visible mastery and progress | progress bar, levels, milestones | punishing failure states, arbitrary difficulty spikes |
| Relatedness (SDT) | connection to others | leagues, social accountability, shared collections | a public leaderboard that exposes low performers |
| Intrinsic motivation | the activity is rewarding on its own | reflective summary, mastery curve | over-rewarding an already-loved action (crowds out the intrinsic drive) |
| Extrinsic motivation | an external reward drives the action | badges, points, streak | withdrawing an earned reward as punishment |
| Philanthropist (Hexad) | purpose, helping others | contribution stats, collective goals | a leaderboard that ranks individuals only |
| Socialiser (Hexad) | connection and interaction | social accountability, shared challenges | a solo-only mechanic with no visibility to others |
| Free Spirit (Hexad) | exploration and autonomy | collections, personalization, optional paths | a forced linear progression |
| Achiever (Hexad) | competence and mastery | levels, badges, milestones | a reward with no skill or effort behind it |
| Player (Hexad) | extrinsic rewards | points, streak, surprise reward | a reward system that feels arbitrary or rigged |
| Disruptor (Hexad) | change, challenging norms | challenges or quests, unconventional milestones | rigid rule enforcement with no flexibility |
