# Mechanics

Catalog of engagement mechanics.

| Mechanic | Serves | Use when | Avoid when | Exemplar |
| --- | --- | --- | --- | --- |
| Progress bar | competence | the task has a knowable end state | the end state is infinite or unclear | Duolingo unit progress bar |
| Daily goal | competence, autonomy | the core action splits into a daily commitment | usage is inherently sporadic | Duolingo daily goal with immediate feedback on completion |
| Streak with freeze and recovery | competence, extrinsic | the core action benefits from daily repetition | the domain has natural gaps (illness, travel) with no recovery path | Duolingo streak freeze |
| Levels or tiers | competence | skill or usage genuinely grows over time | there is no real progression underneath | Duolingo league tiers, bronze to diamond |
| Milestones | competence, relatedness | a meaningful threshold exists (100 days, a claim resolved) | the threshold is arbitrary and meaningless to the user | Alan progress markers on a reimbursement claim |
| Challenges or quests | autonomy, competence | an optional side-goal adds variety without pressure | it competes with or replaces the core action | Duolingo weekly quests |
| Badges | competence, extrinsic | recognizing a specific accomplishment worth remembering | given for trivial or unearned actions | Duolingo achievement badges |
| Collections | autonomy, competence | variety and completionism fit the domain | collecting has no relation to the core action | Duolingo character and item unlocks |
| Leagues or leaderboards | relatedness, competence | competition is opt-in and peers are comparable | it exposes vulnerable or mismatched users to public ranking | Duolingo weekly leagues, opt-out available |
| Personalization | autonomy | the path can adapt to the user's own goal or pace | personalization would mask an unresolved base need | Duolingo goal-based path setup |
| Reflective summary (weekly recap) | competence, autonomy | progress is real but slow-moving and daily feedback is not enough | recaps arrive too often and add noise | Alan weekly reassurance summary of ongoing claims |
| Social accountability | relatedness | peer visibility genuinely motivates the persona | it exposes private or sensitive information (health, finance) | Duolingo opt-in friend streaks and nudges |
| Surprise reward | extrinsic, intrinsic novelty | rare and proportional to a real accomplishment | used to mask an otherwise flat or manipulative loop | Duolingo surprise gem or streak-freeze reward |

Duolingo exemplifies immediate feedback and celebration proportional to the action. Alan exemplifies a calm status, reassurance, and visible progress on a real claim, with no pressure.
