# States

The state matrix every screen in the brief must cover, or mark not applicable.

| State | Must show | Tone |
| --- | --- | --- |
| First use | what this screen is for, and the first action to take | welcoming, low-stakes |
| Empty | why it is empty, and the one action that fills it | an onboarding moment, not a dead end |
| Loading | that progress is happening, and roughly how long | calm, no false precision |
| Partial | what is known now, and that more is coming | honest, no silent gaps |
| Error | what happened in plain language, and the recovery step | a reassurance moment, never blame |
| Success | the outcome achieved, and the next step | confirming, proportional to the stakes |
| Return visit | what changed since last time, ranked first | efficient, skips onboarding |
