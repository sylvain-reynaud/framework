# Screen Data

How to decide what a screen shows, and in what order.

| Rule | Check |
| --- | --- |
| Question-first | the screen answers the one question the persona came with, before anything else |
| One primary | exactly one primary number or status holds the screen's main visual weight |
| Ranked secondary | every other data point is ordered by how much it changes the persona's next decision |
| Progressive disclosure | detail past the primary is one interaction away, never all shown at once |
| Glanceability test | the primary answer reads in 3 seconds at arm's length; if it does not, cut or promote it |

| Reference pattern | Shows |
| --- | --- |
| What would Alan show | the status, the reassurance, the next step, nothing competing for attention |
| What would Duolingo show | the progress, one action, no secondary noise |
