# Moments

What makes one moment in a journey worth remembering.

| Criterion | Check |
| --- | --- |
| Tied to the job | the moment marks the job actually getting done, not an arbitrary screen |
| Proportional | its intensity matches the journey's frequency and consequence: rare and consequential earns more than routine |
| Skippable | the persona can move past it without friction |
| Consent | no sound plays without the user having enabled it |
| One per journey | a journey earns exactly one memorable moment, not one per screen |

| Engagement system | Hook |
| --- | --- |
| `aidd_docs/product/engagement.md` exists | link the moment to one named mechanic: its trigger, its feedback, or its celebration tier |
| `aidd_docs/product/engagement.md` absent | state explicitly that no motivation hook applies; never invent a mechanic |
