# Persistence

## File

- Reuse the dated task folder that already holds this feature's spec or brainstorm: `aidd_docs/tasks/<yyyy_mm>/<yyyy_mm_dd>_<slug>/experience.md`.
- Create a new dated task folder only when no such folder exists for this feature.
- When a folder is stale, ambiguous, or already has `experience.md`, ask before updating.

## Handoff

Hand off to the plan capability with the persisted path. Never invoke it silently.
