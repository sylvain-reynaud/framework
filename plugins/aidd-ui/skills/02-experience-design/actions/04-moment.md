# 04 - Moment

Name the one moment in the journey worth remembering, and whether it hooks into the product's motivation system.

## Input

The shaped flow and screens.

## Output

The journey's one memorable moment and its motivation hook, or an explicit statement that none applies.

## Process

1. **Select.** Apply [moments](../references/moments.md) to choose the single moment worth remembering, tied to the job done.
2. **Justify.** State why the moment fits the journey's frequency and consequence.
3. **Hook.** Apply the engagement table in [moments](../references/moments.md) to link or decline a motivation hook.

## Test

| Case | Pass |
| --- | --- |
| Moment chosen | tied to the job done; exactly one for the journey, never one per screen |
| High-frequency, low-consequence journey | moment kept small and skippable |
| Engagement system present | moment linked to one named mechanic |
| Engagement system absent | motivation hook explicitly stated as none, nothing invented |
| Sound proposed | requires explicit consent or is rejected |
