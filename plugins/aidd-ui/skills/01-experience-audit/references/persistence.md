# Persistence

## File

- Create a new dated task folder by default: `aidd_docs/tasks/<yyyy_mm>/<yyyy_mm_dd>_<slug>/experience-audit.md`.
- Reuse an existing folder only when it is clearly the same current work.
- When a folder is stale, ambiguous, or already has `experience-audit.md`, ask before updating.
- Offer a new dated report instead of touching an old file when in doubt.
