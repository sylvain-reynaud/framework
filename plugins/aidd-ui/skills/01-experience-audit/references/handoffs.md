# Handoffs

| Observed | Capability | Return |
| --- | --- | --- |
| a gap needs feature-level rework before it can be built | the experience design capability | offer it, then stop |
| a gap points to a motivation or habit mechanic | the engagement system capability | offer it, then stop |
| the ranked gaps are ready to build as-is | the plan capability | offer it, then stop |
| no match | none | report what was observed |

Offer the named capability with what was observed, then stop. Never invoke it silently.
