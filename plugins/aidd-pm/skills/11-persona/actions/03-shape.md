# 03 - Shape

Turn the current understanding into one coherent persona.

## Input

The discovered persona understanding.

## Output

A review-ready persona kept in context.

## Process

1. **Compose.** Fill [the template](../assets/persona.md).
2. **Check.** Apply [quality](../references/quality.md).
3. **Show.** Present the complete draft without persisting it.

## Test

| Case | Pass |
| --- | --- |
| Frontmatter | non-empty `goal`; `revision: current` |
| Structure | template order unchanged; every section filled, Hexad type only when assessed |
| Cleanup | no comment, placeholder, or `TODO` remains |
| Quality | every `quality` row passes |
| Handoff | complete draft shown; workspace unchanged |
