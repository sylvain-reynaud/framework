# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently, never write outside a persona.

| Observed | Capability | Return |
| --- | --- | --- |
| a product not yet framed | Product Brief | one-way; no persona is created |
| one independently deliverable behavior for this persona | User Story | one-way |
| a feature ready to be considered for this persona | Experience design | one-way |
| a motivation or habit loop to design for this persona | Engagement system | one-way |
| no match | none | report what was observed |
