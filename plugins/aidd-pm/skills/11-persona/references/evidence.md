# Evidence

Use each source only for what it can support.

| Source | Can support | Cannot establish |
| --- | --- | --- |
| Interviews, support tickets, analytics, session recordings | behavior, pain, and outcomes for real users | that every target user matches |
| App store reviews, forums, competitor reviews | public sentiment and reported experience | target-user truth or frequency |
| Code and interface signals (onboarding, settings, defaults) | what the product already assumes about its users | that users behave as assumed |
| Team belief | a hypothesis worth testing | any user behavior or preference |

| Case | Handling |
| --- | --- |
| Claim backed only by team belief | assumption |
| Consequential external claim | cite an authoritative or firsthand source; label inference |
| Several personas plausible from the same evidence | ask which segment is authoritative; recency is not evidence |
